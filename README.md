# Ammar Alsabateen — Portfolio

Personal portfolio of **Ammar Alsabateen**, AI & Machine Learning Engineer and Web Developer.

🌐 **Live:** https://ammarjm.github.io/

## Built with

- Semantic HTML5, CSS (custom properties, dark / light themes) and vanilla JavaScript
- No frameworks, no build step and no tracking
- Fully responsive, from 320px phones to wide desktops

## Structure

```text
├── index.html      # Page structure and content
├── css/style.css   # Styles and theme tokens
├── js/script.js    # Theme toggle, mobile menu, scroll animations, contact form
└── images/         # Portrait
```

## Run locally

```bash
python -m http.server 8000
```

Then open http://localhost:8000.
